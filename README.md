 # 🎯 Number Guessing Game

A simple and interactive Python console game where the computer randomly selects a number between 1 and 100, and the player tries to guess it. The game provides hints and tracks the number of attempts.

## ✨ Features
- **Random Number Generation**: Computer picks a secret number between 1-100
- **Smart Hints**: Tells you if your guess is "Too High" or "Too Low"  
- **Attempt Counter**: Tracks how many tries you needed to win
- **Input Validation**: Handles invalid inputs gracefully
- **Replay Option**: Play again without restarting the program

## 🚀 How to Play
1. The computer selects a secret number between `1` and `100`
2. You enter your guess
3. The game tells you if your guess is `too high` or `too low`
4. Keep guessing until you find the correct number
5. See your total attempts and play again!

## 🛠️ Technologies Used
- **Language**: Python 3
- **Libraries**: `random` for number generation
